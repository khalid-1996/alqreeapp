# القارئ (Al-Qari)

تطبيق Flutter للاستماع إلى القرآن الكريم وإذاعاته، مع ومضة يومية من القرآن والسنة والأذكار.
بدون تسجيل دخول، وبدون جمع بيانات، وبث فقط (لا تحميل للصوت).

المعرّف: `net.alqareeapp.alqaree`

## الميزات
- القراء والإذاعات بث مباشر، مع مشغل يعمل في الخلفية وAirPlay
- **ومضات اليوم:** آية أو حديث أو دعاء، بترتيب عشوائي ثابت (نفس الومضة لكل الناس في نفس اليوم، ولا تتكرر حتى تمر كلها)
- مشاركة الومضة كصورة: ستوري، بوست، أفقي
- الأذكار مع عداد
- ويدجت: ومضات اليوم، أكمل الاستماع، الأذكار
- إشعارات محلية هادئة يتحكم بها المستخدم: ومضة اليوم، تذكير الجمعة، الأذكار
- المفضلة في SQLite، ويعمل بدون نت
- عربي وإنجليزي

## المحتوى ومصادره
| المحتوى | المصدر |
|---|---|
| التلاوات والإذاعات | [mp3quran.net API](https://mp3quran.net/ar/api) |
| الأحاديث | [موسوعة الأحاديث النبوية HadeethEnc](https://hadeethenc.com) — صحيح متفق عليه فقط، منقول كما هو، ومعه رقمه في صحيح البخاري |
| الآيات والأدعية القرآنية | [Tanzil](https://tanzil.net) — النص العثماني كما هو |
| الأذكار | مضمنة في التطبيق |

كل الومضات في ملف واحد: `assets/data/wamdat.json`.
- **الأحاديث تتحدث تلقائيًا كل جمعة** من الموسوعة (`tool/fetch_hadith.py`)، ولا يُقبل إلا حديث صحيح متفق عليه، من كلام النبي ﷺ، يُفهم بدون شرح، وموجود بنفس لفظه في صحيح البخاري.
- التطبيقات تجيب النسخة الجديدة خلال أسبوع بدون إصدار جديد، وبدون نت تستخدم آخر نسخة محفوظة.
- يشترط أن يبقى المستودع **Public**.

## الإصدارات
غيّر `version:` في `pubspec.yaml` وارفع على `main`، فينشأ Release فيه:
- `alqaree-vX.Y.Z.apk` للتثبيت المباشر على أندرويد
- `alqaree-vX.Y.Z-unsigned.ipa` للآيفون (يحتاج توقيع)

للنشر في المتاجر: Google Play يحتاج AAB موقّع، وApp Store يحتاج توقيع بشهادة حسابك.

## التشغيل محليًا
```bash
flutter create --org net.alqareeapp --project-name alqaree --platforms android,ios .
flutter pub get
flutter run
```

## البنية
```
lib/core    الثيم، النصوص، SQLite، الإشعارات، الويدجت
lib/data    الموديلات، الـ APIs، المحتوى
lib/audio   خدمة التشغيل
lib/state   Riverpod
lib/ui      الشاشات
tool/       تحديث الأحاديث وتجهيز ملفات المنصات
```

## فيديو تيك توك اليومي
- كل ليلة يجهز GitHub Actions فيديو ومضة اليوم وبكرة (`server/video`) وينشره في Release باسم `wamda-videos`.
- سكربت PHP على السيرفر (`server/tiktok`) ينشره على تيك توك كل يوم، ويشغّله n8n.
