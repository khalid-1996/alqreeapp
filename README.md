# القارئ (Al-Qari)

تطبيق Flutter للاستماع لتلاوات القرآن الكريم وإذاعاته، مع حديث ودعاء اليوم والأذكار.

**الإصدار الأول:** بدون تسجيل دخول، بدون جمع بيانات، وبث فقط (لا تحميل للصوت).

## الميزات (v1)
- شاشة ترحيب عند أول تشغيل
- القراء: بحث، فلتر بالرواية، صفحة القارئ وقائمة سوره
- الإذاعات: بث مباشر مع المفضلة
- مشغل بالخلفية مع التحكم من شاشة القفل والإشعار، وأوضاع التشغيل (التالي، تكرار، عشوائي)، و AirPlay من مركز التحكم
- ومضات اليوم: حديث أو دعاء أو آية، يتبدل كل يوم، والخط يصغر للنصوص الطويلة بدل قصها
- مشاركة كصورة بثلاث مقاسات: ستوري 9:16، بوست 4:5، أفقي 16:9
- الأذكار (الصباح، المساء، عامة) مع عداد
- المفضلة في SQLite، وكاش للقوائم يشتغل بدون نت
- ويدجت للشاشة الرئيسية: ومضات اليوم، أكمل الاستماع، والأذكار مع العداد
- عربي (أساسي) وإنجليزي

## المصادر
| المحتوى | المصدر |
|---|---|
| التلاوات والإذاعات وأسماء السور | [mp3quran.net API v3](https://mp3quran.net/ar/api) |
| الأحاديث | [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api) (Public Domain) |
| الأذكار والأدعية | مضمنة في التطبيق |

## البنية
```
lib/
  core/      الثيم، النصوص (عربي/إنجليزي)، قاعدة SQLite
  data/      الموديلات، الـ APIs، المحتوى المحلي، Repository (كاش أولًا)
  audio/     خدمة التشغيل (just_audio + audio_service)
  state/     Riverpod providers
  ui/        الشاشات والمكونات
```
الشاشات ما تنادي أي API مباشرة، كل شي عبر `Repository`.

## البناء
مجلدات `android/` و `ios/` تتولد بـ `flutter create`، وما نحفظ في المستودع إلا الملفات المعدلة (AndroidManifest و MainActivity).

```bash
flutter create --org net.alqareeapp --project-name alqaree --platforms android,ios .
flutter pub get
flutter run
```

المعرّف: `net.alqareeapp.alqaree`

## الإصدارات
كل push على `main` يبني APK و IPA للتأكد من سلامة الكود.
لإصدار جديد غيّر `version:` في `pubspec.yaml` (مثلًا `1.0.1+2`) وارفع على `main`،
فيُنشأ Release باسم `v1.0.1` تلقائيًا فيه:
- `alqaree-v1.0.1.apk`: للتثبيت المباشر على أندرويد (موقّع بمفتاح تجريبي)
- `alqaree-v1.0.1-unsigned.ipa`: للآيفون بدون توقيع، يحتاج توقيع قبل التثبيت

> للنشر في المتاجر: Google Play يحتاج AAB موقّع بمفتاح رفع خاص، و App Store يحتاج البناء من Xcode بشهادة حسابك.
